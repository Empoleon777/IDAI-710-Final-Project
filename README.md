# IDAI-710-Final-Project

## Linear Model
This project implements a simple Linear Model for analyzing transportation data and predicting future trends.
---

## Operation
You can examine the individual models and their performance in src/Models. Simply running everything all the way through will show you the whole process, and will save a graph to the Graphs folder. The Results folder contains additional spreadsheets comparing the differences between actual test data and what the models predicted.
---

## Requirements
- Python 3.9 or higher  
- Required libraries:
  - pandas  
  - numpy
  - scikit-learn  
  - xgboost
  - keras
  - matplotlib
---

## Installation
Install the required dependencies either with requirements.txt, or with:

```bash
pip install pandas numpy scikit-learn keras xgboost matplotlib
