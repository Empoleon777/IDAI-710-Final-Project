# IDAI-710-Final-Project

## Linear Model
This project compares three models' efficacy at predicting future trends in a transportation system.

## Operation
You can examine the individual models and their performance in src/Models. Simply running everything all the way through will show you the whole process, and will save a graph to the Graphs folder. The Results folder contains additional spreadsheets comparing the differences between actual test data and what the models predicted. The optimization code is in src/Notebooks. There isn't much to this one beyond just running it; it generates its own test code.

## Requirements
- Python 3.9 or higher  
- Required libraries:
  - pandas  
  - numpy
  - scikit-learn  
  - xgboost
  - keras
  - matplotlib
